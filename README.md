## 专注于极简PC端dock栏

我一直很喜欢macos的dock栏，但是市面上的dock栏软件虽然功能很全，也很美观，但是资源占用很大。对我来说多了很多不需要的功能，所以我就想做一个极简的dock栏，只包含dock栏最基本的功能，资源占用尽可能少，目前测试下来只有几M。

### 初版设计

```MiniDock.exe``` 已做好，是 ```64 位```免安装程序，大小约 ```135 KB```，双击即可运行。用claude做的。

### 功能
- 自定义拖拽图标固定
- 支持固定网页应用（好多别的dock栏软件都不支持）
- 支持自定义图标
- 支持添加分割线
- 支持悬停放大和名称标签
- 调整dock栏大小、位置、缩放、不透明度、图标间距……

### 用法

- 添加图标：把应用、快捷方式、.exe、文件夹，或浏览器里的网址直接拖到 Dock 上，空位会自动让开。
- 文件夹：单个或多个都行，每个文件夹是一个独立图标，保留系统原来的样子。
- 网页应用：默认用 Edge 的应用窗口打开
  - 没有 Edge 就用 Chrome，再不行用默认浏览器
  - 每个网址可以单独切换。
  - 网站图标会在后台自动下载，下载前用字母图标代替。
  - 支持自定义图标
  - 支持链接快捷方式
- 管理图标：拖动可以换位置，拖到 Dock 外面松手就是移除，右键图标有重命名、在右侧加分割线、在文件夹中显示等选项。
- 设置：右键 Dock 空白处，或双击托盘图标。可调图标大小、放大后大小、间距、距底部边距、栏内边距、圆角、不透明度，另有深色主题、自动隐藏、开机自启动等开关。
- 配置文件：保存在 exe 同目录的 MiniDock.ini；目录不可写时改存到 %APPDATA%\MiniDock。
